# Rally Player

Player de música retrô com tema de vôlei. Toca os arquivos de áudio do seu celular, funciona offline e pode ser instalado como app no Android (PWA).

## Arquivos
`index.html`, `style.css`, `app.js`, `sw.js`, `manifest.json`, `icon-192.png`, `icon-512.png`

## Publicar
Envie todos os arquivos para a raiz de um repositório e ative o GitHub Pages (Settings → Pages → branch `main`, pasta `/ (root)`).

## Atualizar
Ao alterar algum arquivo, troque o número em `CACHE` no `sw.js` (por exemplo, `rally-v2`) para o celular baixar a versão nova.
